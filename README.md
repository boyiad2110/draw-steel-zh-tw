# 英雄爭鋒

《英雄爭鋒》是一個以繁體中文提供 Draw Steel 角色建立與規則速查功能的非官方粉絲專案。

目前專案處於基礎建設階段。第一個產品週期聚焦：

- 以 Heroes 為首發角色內容來源。
- 支援 1 級創角與 1 → 2 級升級，以驗證 progression 模型。
- 以 `DrawSteelRulesReferenceV1.pdf` 為 MVP 範圍提供繁中規則速查。
- 本機角色儲存、JSON 匯入／匯出與分享連結；MVP 不做帳號與後端。
