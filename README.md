# 英雄爭鋒

《英雄爭鋒》是一個以繁體中文提供 Draw Steel 角色建立與規則速查功能的非官方粉絲專案。

目前專案處於規劃與基礎架構階段。首個開發目標是建立可維護、可驗證、可追溯來源的內容與翻譯工作流，之後再逐步實作：

- Heroes 規則內容
- 1～2 級角色建立與升級
- 以 `DrawSteelRulesReferenceV1.pdf` 為範圍的規則速查
- 本機角色儲存、JSON 匯入／匯出與分享連結

> This is an unofficial Draw Steel fan project. Draw Steel is created by MCDM Productions.
